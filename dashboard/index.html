How to use LassiNet

A live map of your network. Once you know the two colour codes, the rest is read at a glance.

What does Block do?

Block source on a threat card adds a firewall rule for that alert's source IP — never the victim. Block IP on a device adds the same rule for that device. LassiNet marks it blocked, drops flows from it, stops counting and animating them, and records a BLOCK entry in Firewall rules. Alert history is kept.

In demo mode the rule is simulated (mock provider): nothing on your PC changes. In live mode only nftables currently enforces blocks; the OPNsense/pfSense provider is a placeholder and reports an error instead of pretending to block. Unblock - on a blocked device or in a rule - reverses it.

Demo tip: critical attacks are auto-blocked by default, so the simulation can go quiet. Unblock the attacker in Firewall rules to let it continue.

Traffic dots

Normal flow — one soft blue dot per sampled flow.
Attack flow — a red trail moving toward the victim.
Press D to hide or show all dots.

Device colours

Purple = router · blue = server / Internet · green = workstation / trusted · orange = IoT / suspicious · grey = printer. A red skull marks a confirmed attacker; a dashed red ring and a dimmed node mean the firewall blocked it.

Act on a device

Click a device to select it and open its action bar. Right-click for the trust menu. Double-click to rename it. B blocks the selected host (never the router or Internet).

Right column

Threats are detections, each with a one-click Block source. Firewall lists active blocks; Unblock removes one. Log is the full event stream. The column scrolls as one page.
