How to use LassiNet

A live map of your network. Once you know the two colour codes, the rest is read at a glance.

What does Block do?

Block source on a threat card adds a firewall rule for that alert's source IP — never the victim. Block IP on a device adds the same rule for that device. LassiNet marks it blocked, drops flows from it, stops counting and animating them, and records a BLOCK entry in Firewall rules. Alert history is kept.

In demo mode the rule is simulated (mock provider): nothing on your PC changes. In live mode nftables, OPNsense or Windows Firewall can enforce blocks; pfSense is still a placeholder and reports an error instead of pretending to block. Unblock - on a blocked device or in a rule - reverses it.

Demo tip: high and critical attacks are auto-blocked by default, so the simulation can go quiet. Unblock the attacker in Firewall rules to let it continue. In live mode auto-block is off and only touches external sources, so a false positive cannot take your LAN down.

Live safety

Set LASSI_LIVE_ALLOW to your own CIDR (for example 192.168.0.0/24): live mode requires it and refuses any other network (LASSI_LIVE_ALLOW_ANY=1 is the explicit lab override); ARP discovery skips disallowed networks. LASSI_PASSIVE=1 observes captured flows without ARP sweeps or port probes. LASSI_DRY_RUN=1 records and shows blocks without changing the firewall. In live mode auto-block is off by default; if enabled, auto-blocks expire after LASSI_AUTO_BLOCK_TTL (1 h by default).

Device colours

Purple = router · blue = server / Internet · green = workstation / trusted · orange = IoT / suspicious · grey = printer. A red skull marks a confirmed attacker; a dashed red ring and a dimmed node mean the firewall blocked it. Trusted devices are protected by the server: they can never be blocked, not even by the auto-block.

Act on a device

Click a device to select it and open its action bar. Right-click for the trust menu. Double-click to rename it. Use the Find a device box in the toolbar (or /) to search by name, IP, type or role. B blocks the selected host (never the router, the Internet or a trusted device).

How devices are identified

In live mode (unless passive) LassiNet sweeps the LAN with ARP (IP + MAC), then asks the local resolver for a name and fingerprints a handful of ports (631/9100 printer, 554 camera, 62078 iPhone, 8009 Chromecast, 5000 NAS…) to pick the icon. Results are cached per MAC, so each device is probed once per 12 h and never on the gateway. In demo mode the devices are scripted.

Right column

Threats are detections, each with a one-click Block source. Firewall lists active blocks; Unblock removes one. Log is the full event stream. The column scrolls as one page.
